Back-End Processing · 23

검파와 압축Detection & Log Compression

ADC 가 넘긴 숫자를 FPGA 가 받는다. 채널을 합쳐 주사선을 만드는 DAS 빔포밍(12·13장)이 첫 디지털 작업이며, 그 결과는 아직 반송파가 실린 RF 신호이다. 여기서 포락선만 벗겨내고(검파) 진폭 범위 100 dB 를 화면의 계조로 눌러야(압축) 비로소 영상이 된다.

01

먼저 DAS — 채널을 주사선으로Beamforming, the first digital op

ADC 는 소자 채널마다 숫자열을 내놓는다. 이들에 깊이별 지연을 주고 더하면 한 방향의 주사선 하나가 얻어지는데, 이것이 지연-합(delay-and-sum, DAS) 수신 빔포밍이다(12·13장). 이 작업을 아날로그가 아니라 디지털에서 하는 이유는, 깊이마다 지연을 바꾸는 동적 집속이 숫자로만 가능하기 때문이다.

DAS 를 어느 신호에 거는가. 예전에는 RF 표본에 직접 지연-합을 했는데, 반송파 때문에 표본 간격보다 훨씬 미세한 지연이 필요해 고배율 보간이 들었다. 요즘 장비는 흔히 먼저 IQ 로 내리고(다음 절) decimation 한 뒤 그 IQ 에 DAS 를 건다. 기저대역에서는 지연이 정수-표본 이동(거친 부분)과 위상회전 e−j2πf₀τ(미세한 부분)으로 갈라지므로, RF 보간 없이도 정밀하면서 표본율은 약 10배 낮아진다.

그래도 검파는 DAS 뒤에 온다

여기서 IQ 변환과 포락선 검파를 구별해야 한다. IQ 변환은 위상을 그대로 지닌 복소신호를 만들 뿐이므로 DAS 앞에 놓을 수 있다. 그러나 포락선을 취하는 연산 √(I²+Q²) 은 위상을 버린다. 위상을 버리면 채널을 코히런트하게 더할 수 없어 집속 자체가 성립하지 않으므로, 포락선 검파는 언제나 DAS 뒤에 온다(19장). IQ 변환이 앞으로 오는 것과 검파가 뒤에 오는 것은 서로 다른 이야기이다.

이 장은 그렇게 얻은 주사선 하나를 영상 밝기로 바꾸는 단계를 다룬다.

02

검파 — 반송파를 벗긴다Envelope detection

빔포밍 결과는 ~5 MHz 반송파가 진동하는 RF 신호이며, 스펙트럼은 ±f₀ 양쪽에 대칭으로 놓인다. 화면에 필요한 것은 진폭, 즉 포락선뿐이므로 반송파를 벗긴다. 이때 쓰는 해석신호(analytic signal)를 만드는 길이 두 가지 있다.

  • IQ 복조(quadrature demodulation) · 하향혼합 → LPF → decimation 의 순서로 진행한다. RF 에 e−j2πf₀t 를 곱하면 스펙트럼이 f₀ 만큼 내려가 신호 대역이 0 Hz 로 오고 원치 않는 상은 −2f₀ 로 밀려난다. LPF 가 −2f₀ 의 상을 지우면 기저대역 복소신호 I + jQ 만 남고, 포락선은 √(I²+Q²) 로 얻는다. 대역이 좁아졌으므로 표본을 훨씬 성기게 다시 뽑을 수 있는데 이것이 decimation 이다. 이 IQ 는 도플러의 위상 정보와 DAS 에도 그대로 쓰인다. 다만 하향혼합에 f₀ 값을 알아야 한다.
  • 힐베르트 변환(Hilbert transform) · 90° 위상천이로 짝 신호 x_H 를 만들어 x + j·x_H 를 구성하면 스펙트럼에서 음의 주파수(−f₀)만 지워지고 +f₀ 는 그대로 남는다(한쪽 스펙트럼). f₀ 를 몰라도 되고 반송파가 유지되므로(통과대역) 그 자체로는 decimation 을 하지 않는다.

두 방식이 내놓는 포락선은 같다. 무엇이 구현에 편한가의 선택이며, IQ 는 데이터량과 도플러에서, 힐베르트는 f₀ 를 몰라도 된다는 점에서 유리하다.

※ 표본율은 약 10배 낮아지지만 IQ 는 복소수라 한 표본에 두 값이 들어가므로, 저장·전송해야 하는 값의 개수로 세면 감소폭은 그 절반인 약 5배이다.

인터랙티브 · IQ vs Hilbert — 시간 파형 + 주파수 스펙트럼—
지금 방식—

위 = 시간 파형 · 아래 = 주파수 스펙트럼. IQ 에서는 하향혼합이 신호를 0 Hz, 즉 기저대역으로 내리고 −2f₀ 의 상은 LPF 가 제거하며, 대역이 좁아져 decimation 이 가능해진다 — I·Q 는 반송파가 없는 저주파 신호이다. Hilbert 에서는 −f₀ 만 지우고 +f₀ 는 유지되므로 x 와 x_H 에 반송파가 남는다. 포락선(앰버)은 두 방식에서 동일하다.

03

로그 압축 — 100 dB 를 계조로Log compression

검파된 포락선의 진폭은 강한 경계와 약한 조직 사이에 100 dB, 즉 10만 배에 이른다. 반면 화면이 낼 수 있는 것은 256 계조뿐이므로 그대로는 담을 수 없다. 그래서 로그로 눌러(gray ∝ log 진폭) 넓은 범위를 계조에 대응시킨다. 로그여야 약한 것과 강한 것을 한 화면에 동시에 보여줄 수 있다. 표시할 동적범위(dynamic range) 창을 좁히면 대비가 오르고 약한 에코는 잘리며, 넓히면 미세 계조가 다 보이지만 전체가 흐릿해진다. 장비의 동적범위 손잡이가 이것이다.

100 dB 는 어디서 왔는가 — 22장 ADC 와의 관계

22장에서 ADC 는 12~14비트로 74~86 dB 를 담는다고 했다. 그런데 여기서는 100 dB 를 압축한다. 모순이 아니다 — DAS 가 채널을 코히런트하게 더하면서 동적범위를 넓혀 주기 때문이다. 신호는 채널 수 N 배로 커지지만 채널마다 무상관인 잡음은 √N 배로만 커지므로 20 log N/√N 만큼 이득이 생긴다. 19장의 채널 64개라면 18 dB 이고, 14비트 ADC 의 86 dB 에 더하면 104 dB 로 100 dB 급이 된다.

여기의 256 계조는 표시 단계의 것으로 8비트에 해당하며, ADC 의 12~14비트와는 다른 층이다. ADC 는 들어오는 신호를 몇 단계로 나누는가이고, 계조는 사람이 볼 화면을 몇 단계로 낼 수 있는가이다. 그 사이를 잇는 것이 로그 압축이다.

인터랙티브 · 동적범위 창에 따른 B-모드 영상—

왼쪽 = B-모드 영상(경계·조직·저에코 병변·낭종·심부) · 오른쪽 = 압축 곡선과 각 구조가 받는 회색값. 창을 좁히면(예: 40 dB) 병변과 낭종이 검게 잘려 경계가 또렷해지고, 넓히면(예: 80 dB) 미세 계조까지 보이지만 전체가 회색으로 흐릿해진다. 같은 데이터에 창만 다르게 씌운 것이다.

한 장 정리 · Summary
  • DAS · 채널에 지연-합 → 주사선 하나(12·13장) · 요즘은 decimated IQ 에 DAS(정수표본+위상회전 e−j2πf₀τ)
  • 빔포밍 결과 = RF · 스펙트럼 ±f₀ 대칭 — 화면엔 진폭(포락선)만 필요
  • IQ 변환은 DAS 앞도 가능, 포락선 검파는 언제나 DAS 뒤 · |·| 이 위상을 버려 코히런트 합이 깨지므로
  • IQ 복조 = 하향혼합+LPF+decimation · ×e−j2πf₀t → 0 Hz · LPF 가 −2f₀ 제거 · 표본율 ~10배↓(복소라 값 개수는 ~5배↓)
  • Hilbert = 해석신호 · −f₀ 만 제거, +f₀(반송파) 유지 · f₀ 불필요·구현 단순 · decimation 은 안 함
  • 두 방식의 포락선은 같다 · IQ 는 데이터량·도플러에서, Hilbert 는 f₀ 를 몰라도 되는 점에서 유리
  • 진폭 100 dB(10만 배) → 256 계조 · 로그 압축(gray ∝ log 진폭)이라야 약·강 동시 표시
  • 100 dB 의 출처 · ADC 86 dB + DAS 64채널 이득 18 dB ≈ 104 dB (22장) · 256 계조는 표시 8비트로 다른 층
  • 동적범위 창 · 좁히면 대비↑(약한 에코 잘림), 넓히면 계조↑(흐릿)
