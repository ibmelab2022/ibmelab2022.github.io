Pulse Inversion and Amplitude Modulation펄스 반전과 진폭 변조

부록 A4 는 필터로 2f₀ 를 잘라냈다. 그런데 기본파의 꼬리가 새어 들어오고, 필터를 좁히면 축방향 분해능을 잃는다. 필터를 아예 쓰지 않는 길이 있다 — 두 번 송신하고 더하면 선형 성분이 저절로 지워진다.

먼저 — 왜 두 번 쏘는가

부록 A4 는 필터로 2f₀ 를 잘랐다. 그런데 f₀ 의 꼬리가 2f₀ 대역으로 새어 들어온다(harmonic leakage). 필터를 좁히면 축방향을 잃고 넓히면 기본파가 섞인다.

  • 펄스 반전(pulse inversion, PI) · p 와 −p 를 송신하고 더한다. 조직이 선형이면 응답도 부호가 뒤집히므로 합이 정확히 0 이 되어 필터 없이 지워진다.
  • 진폭 변조(amplitude modulation, AM) · 부호 대신 크기를 바꾼다. 전체 한 번과 반쪽 두 번을 송신해 r(p) − 2r(p/2) 로 조합한다.
  • 살아남는 것은 비선형 성분뿐이다. 오른쪽 스펙트럼에서 무엇이 지워지고 무엇이 남는지 볼 수 있다.
인터랙티브 · 두 번 쏘고 더하면 선형이 지워진다
선형 잔류—
2f₀ (짝수)—

송신 횟수—회

① 송신 파형 → ② 돌아온 두 에코 → ③ 둘을 조합한 잔류, 세 칸으로 본다. 파랑과 빨강이 두 에코이며, PI 는 서로 뒤집혀 더하면, AM 은 거의 같아 빼면 어느 쪽이든 선형이 정확히 0 이 되고 비선형만 남는다(③은 작아서 확대해 그린다). 오른쪽 스펙트럼이 그 결과이며 판독값도 스펙트럼 성분이다.
버튼으로 AM 으로 바꾸면 차이가 드러난다. PI 는 짝수(2f₀)만 남겨 넓은 대역이 필요하지만, AM 은 홀수도 남기고 그것이 기본파 대역 안(f₀·3f₀)이라 대역폭 요구가 없다. a₃ 를 키우면 AM 은 f₀·3f₀ 잔류가 커지는데 PI 는 전혀 변하지 않는다 — PI 가 홀수를 죽인다는 증거이다.
a₂ 를 0 으로 내리면 PI 의 잔류가 완전히 사라진다 — PI 가 보는 것은 오직 짝수 비선형뿐이기 때문이다.

01

다항식 하나로 다 보인다A polynomial says it all

산란체의 응답을 압력의 다항식으로 쓴다 — 선형 항에 2차와 3차를 더한 형태이다.

r(p) = a₁p + a₂p² + a₃p³
a₁ = 선형(조직 대부분) · a₂ = 짝수 하모닉의 씨앗 · a₃ = 홀수 하모닉의 씨앗

펄스 반전은 p 와 −p 를 송신하고 더한다. 대입만 하면 결과가 나온다.

r(p) + r(−p) = 2a₂p²
선형도 3차도 부호가 뒤집혀 사라지고 2차만 2배로 남는다 — 주파수로 풀면 2f₀ 성분의 진폭이 a₂ 로, 단일 에코의 2f₀(a₂/2) 대비 2배이다
PI 는 홀수 하모닉도 같이 죽인다

홀수 항은 (−p)³ = −p³ 이므로 선형과 함께 지워진다. 살아남는 것은 짝수뿐, 곧 2f₀ 이다. 부록 A4 의 필터가 하던 일을 필터 없이 하는 셈이라 기본파 누출(harmonic leakage)이 원리적으로 0 이고, 축방향 분해능을 위해 대역을 좁힐 필요도 없다.

02

진폭 변조 — 홀수를 살린다Amplitude modulation

진폭 변조는 부호가 아니라 크기를 바꾼다. 반쪽 진폭으로 두 번, 전체 진폭으로 한 번 송신해 다음과 같이 조합한다.

r(p) − 2·r(p/2) = a₂p²/2 + 3a₃p³/4
선형은 지워지고 2차와 3차가 모두 남는다 — 주파수로는 2f₀ 가 a₂/4, 홀수는 f₀ 가 9a₃/16 · 3f₀ 가 3a₃/16 이다 (a₂ = 0.15 · a₃ = 0.04 에서 0.1050 — 판독값과 일치)
왜 홀수를 살리는 것이 중요한가 — 대역폭 때문이다

2f₀ 를 받으려면 탐촉자가 f₀ 와 2f₀ 를 둘 다 담아야 한다(부록 A4 의 대가). 그런데 홀수 차 비선형은 스펙트럼이 송신 대역 안으로 접혀 들어온다. 넓은 대역폭이 아예 필요 없다는 뜻이다. 조영제는 낮은 MI 에서도 기본파 근처에 비선형 성분을 내므로(32장), AM 이 조영 영상에서 유리하다.

둘을 합친 진폭·위상 동시 변조(AMPI)가 상용 장비의 표준이며, 대신 송신이 3번이라 프레임률이 1/3 이 된다.

03

움직이면 무너진다Motion breaks the cancellation

상쇄는 두 펄스가 같은 것을 본다는 전제 위에 선다. 그 사이에 조직이 Δx 움직이면 왕복 위상이 2kΔx 어긋나 선형 항이 완전히는 지워지지 않는다. 남는 크기는 |1 − ej2kΔx| = 2|sin(kΔx)| 이다.

인터랙티브 · 움직임이 남기는 잔류—
펄스 간격—µs
그동안 이동—µm
선형 잔류—dB
조영/조직 대비—

정지 조직은 완전히 지워진다. 그런데 심근처럼 20~50 mm/s 로 움직이면 PRF 5 kHz 에서 잔류가 −16 dB(20 mm/s)에서 −8 dB(50 mm/s) 까지 올라와 하모닉 신호를 덮어버린다.
PRF 를 올리면 간격이 짧아져 잔류가 준다 — 그래서 PI 는 빠른 송신을 원한다(부록 A1).
느린 PRF 와 빠른 조직이 겹치면 잔류가 0 dB 를 넘기도 한다. 두 에코가 상쇄되기는커녕 보강되어 단일 에코보다 커지는 경우이다.

정리하면 PI 의 대가는 두 가지이다 — 송신 2배로 인한 프레임률 1/2과 움직임 민감성이다. 문헌에 따르면 PI 도플러는 같은 펄스의 하모닉 영상보다 조영 대 조직 대비를 3~10 dB 더 준다(Simpson 등).

한 장 정리 · Summary
  • r(p) = a₁p + a₂p² + a₃p³ · 다항식 하나에 전부 들어 있음
  • PI: r(p) + r(−p) = 2a₂p² · 선형과 홀수까지 지워지고 짝수만 2배
  • 필터가 필요 없다 · harmonic leakage 원리적으로 0 · 대역을 좁힐 필요 없어 축방향 유지
  • AM: r(p) − 2r(p/2) = a₂p²/2 + 3a₃p³/4 · 선형만 지우고 홀수도 살림 (2f₀ = a₂/4 · f₀ = 9a₃/16)
  • 홀수는 송신 대역 안으로 접혀 들어옴 → 넓은 대역폭이 필요 없음 — 조영제에 유리 (32장)
  • AMPI = 둘을 합침 · 상용 표준 · 대신 송신 3회 → 프레임률 1/3
  • 움직임이 상쇄를 깬다 · 잔류 = 2|sin(kΔx)| · PRF 5kHz 에서 5mm/s −28dB · 20mm/s −16dB · 50mm/s −8dB
  • 느린 PRF + 빠른 조직이면 잔류가 0 dB 를 넘어 보강되기도 함
  • 대가 둘 · 송신 2~3배(프레임률) + 움직임 민감 → 빠른 송신을 원함 (부록 A1)
